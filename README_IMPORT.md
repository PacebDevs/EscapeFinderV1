Generador de plantilla Excel para salas

1) Objetivo
   - Generar `output/salas_template.xlsx` con hojas y encabezados según `src/data/mapping_salas.json`.

2) Requisitos
   - Python 3.8+
   - Instalar deps:

```bash
pip install -r requirements.txt
```

3) Uso

```bash
python scripts/generate_excel.py
```

El fichero resultante se guardará en `output/salas_template.xlsx`. Si lo quieres con más ejemplos, puedo añadir más filas de ejemplo por hoja.
